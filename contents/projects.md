### Anaemia diagnosis with large language models

Explored diagnostic pathway discovery with GPT-4 and LLaMA on synthetic medical cohorts. I evaluated generated pathways against expert hematology standards and used physician-defined decision trees to encourage clinically aligned reasoning.

### Steam search engine

Built an inverted-index search system for more than five million Steam user reviews, with sub-second query latency and hybrid BM25 scoring. The project also used a cloud-hosted DistilRoBERTa pipeline for multi-label sentiment classification.

### Hypertension pathways and Generation Scotland

Created an RDF/OWL knowledge graph connecting NICE guidelines with Generation Scotland data, then built an LLM-driven SPARQL generation pipeline to support semantic queries and compare treatment adherence across cohorts.

### Quantitative portfolio optimization

Developed a portfolio optimization engine using asset clustering, Sharpe ratio maximization, and ARIMA and ensemble forecasting. In a 2016–2024 backtest, the strategy outperformed the FTSE MIB benchmark.
